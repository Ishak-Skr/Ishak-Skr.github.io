# Ishak-Skr Personal Website

A standalone personal portfolio for Ishak-Skr, built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — small animations and current-year footer
- `favicon.svg` — site icon

## GitHub Pages

Create a public repository named exactly:

`Ishak-Skr.github.io`

Upload all four website files to the root of the repository.

Then go to:

**Repository → Settings → Pages**

Under **Build and deployment**, choose:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

Click **Save**.

Your site should become available at:

`https://ishak-skr.github.io`

The first deployment can take a few minutes.

## Editing the site

Most text is inside `index.html`.

Colors and layout are in `style.css`.

The GitHub profile link is currently:

`https://github.com/Ishak-Skr`

Replace/add links in `index.html` as your online presence grows.

## Important

The site currently uses Google Fonts through an `@import` in `style.css`. The site itself still works if the font service is unavailable; the browser will fall back to system fonts.
